QUICK START
================================================================================

1. Install dependencies:
   bun install

2. Start development server:
   bun run dev

3. Configure AI Providers:
   - Navigate to AI Providers in the sidebar
   - Choose a provider (e.g., Phi-3.5 Vision for free NVIDIA)
   - Get API key from https://build.nvidia.com/ or https://openrouter.ai/
   - Click "Add API Key", paste key, validate, and save

4. Enable Cloud OCR:
   - Go to Scan Product page
   - Toggle "Use Enhanced Cloud Accuracy"
   - Upload and scan product label
